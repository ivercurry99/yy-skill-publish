# 法律合规自查清单 · 发布前逐项确认

> 建议打印或贴进 PR checklist，每一条确认后再打勾。

---

## 一、商标与品牌词

- [ ] 项目名、目录名、文件名中没有把他人注册商标当作通用词使用：
  - [ ] 未使用 `ChatGPT` / `GPT-4` / `GPT-x` 作为产品名（改为「兼容 OpenAI 系列大模型」等描述语句）
  - [ ] 未使用 `抖音` / `微信` / `App Store` / `YouTube` / `Google` / `GitHub` 等品牌作为自己产品名称
  - [ ] `GitHub` 仅作为平台名称提及，未将 Octocat / GitHub Logo / GitHub 品牌色组合直接放进 README 装饰
  - [ ] Seedream / DALL·E 3 / FLUX / Stable Diffusion 等仅作为「提供服务的模型名」正常描述，没有将其官方 Logo 贴入 README
- [ ] 自己的项目名后面没有加 ® / ™（除非持有商标注册证）
- [ ] 演示截图 / Hero 图中字体均为开源可商用字体（Noto Sans / 思源黑体 / 站酷系列等），未用方正 / 汉仪 / 蒙纳等未授权字体
- [ ] 人像照片来源合法（本人拍摄 / Unsplash / Pexels 授权），未从社交平台下载用户照片
- [ ] README 中没有政治、色情、毒品、暴力、赌博、未成年人相关内容：发现即删除

## 二、LICENSE 文件

- [ ] 仓库根目录有 `LICENSE` 文件（不是 license.txt / LICENSE.md / 中文「许可证.md」——文件名必须严格大写）
- [ ] 推荐协议：MIT License（宽松，企业和个人都敢用；商业项目可搭配 Apache 2.0）
- [ ] LICENSE 首行严格是 `MIT License`（首行空着 / 写中文会导致 GitHub 识别不到许可证徽标）
- [ ] 第三行是标准版权声明：`Copyright (c) <年份> <你的 GitHub 用户名>`
- [ ] 全文使用官方 19 行英文版本，不把条款翻译成中文（Open Source Initiative 只认英文原文）
- [ ] 校验：`gh repo view <owner>/<repo> --json licenseInfo` 输出的 `licenseInfo.spdxId` = `"MIT"`

## 三、敏感信息与隐私

全局搜索以下模式，命中必须清理：
- [ ] Token 类：`ghp_*`、`sk-*`、`xoxb-*`、`AKIA*`、`Bearer [A-Za-z0-9._-]{20,}`
- [ ] 个人隐私类：手机号（`1[3-9]\d{9}`）、身份证、银行卡、具体住址、邮箱（非必要不放）
- [ ] 真实姓名（非必要不放；必要时只放 GitHub 用户名 + 英文名缩写）
- [ ] 内网 URL：`http://192.168.*`、`http://10.*`、`.internal` 域名
- [ ] 本地路径（用户个人目录）：`C:\Users\<任意名>`、`/home/<任意名>` → 替换为 `$HOME/project`
- [ ] 私有仓库地址：任何未公开仓库的链接一律删除
- [ ] 测试账号 / 演示账号：演示视频或截图里不能出现可登录的真实凭据

## 四、第三方内容引用合规

- [ ] README 引用的代码片段、文章段落、图片都有明确出处链接（除非是原创）
- [ ] 借鉴的开源项目在 README 致谢段落中给出原项目链接
- [ ] 文档 / 截图中使用了第三方库 logo 做对比时，旁边标注对应商标归属，例如：
  > ChatGPT® 是 OpenAI 注册商标；本项目仅描述「兼容其 API 格式」，与 OpenAI 无官方关联。
- [ ] 没有把别人的付费课程 / 会员内容截图放进仓库（个人使用不等于可公开传播）
